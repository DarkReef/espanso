# Импорт и экспорт конфигурации

Studio создаёт пакет `.respanso-config` только из пользовательской логики:

```text
match/**/*.yml
match/**/*.yaml
scripts/**/*.rhai
```

## Что не переносится

- `config/`;
- `runtime/`;
- `packages/`;
- журналы, временные файлы и резервные копии.

## Импорт

До замены файлов Studio:

1. проверяет структуру и пути пакета;
2. проверяет YAML;
3. компилирует Rhai;
4. создаёт резервный пакет текущих `match/` и `scripts/`;
5. устанавливает данные через временную staging-папку;
6. восстанавливает исходные папки при ошибке.

Пакет формата версии 2 несовместим со старыми пакетами, которые включали внутренний `config/`.
