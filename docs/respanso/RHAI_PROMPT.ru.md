# Промпт для генерации Rhai-скриптов rEspanso

Скопируйте текст ниже в выбранную языковую модель и замените описание задачи в конце.

```text
Ты пишешь Rhai-скрипт для rEspanso.

Требования:
1. Используй синтаксис Rhai, совместимый со встроенным движком rEspanso.
2. Пиши простой, детерминированный и читаемый код.
3. Не используй shell, сеть, файловую систему и внешние процессы, если это отдельно не разрешено.
4. Явно перечисли ожидаемые входные переменные.
5. Проверь пустые и некорректные входные значения.
6. Не используй бесконечные циклы, eval и отладочную печать.
7. Итоговый текст или значение верни последним выражением скрипта.
8. Не выдумывай функции Rhai. При сомнении используй только базовые операции со строками, числами, массивами, map, if и функциями.
9. Комментарии должны объяснять только неочевидную логику.
10. После кода предоставь:
   - имя файла в scripts/;
   - список входных переменных;
   - ожидаемый результат;
   - пример подключения из YAML rEspanso;
   - три тестовых примера, включая граничный.

Контекст:
- скрипты находятся в scripts/**/*.rhai;
- правила находятся в match/**/*.yml|yaml;
- Match Studio компилирует Rhai и показывает ошибки;
- в тестовой среде могут быть доступны trigger, input и clipboard;
- решение должно работать локально и не передавать данные наружу.

Формат ответа:
1. Название и назначение.
2. Полный код Rhai в одном блоке.
3. Пример YAML.
4. Таблица тестов.
5. Краткие ограничения.

Задача:
<подробно опишите требуемое вычисление или преобразование>
```

Перед использованием медицинского или юридического расчёта вручную проверьте формулы и граничные условия.
