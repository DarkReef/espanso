# Решение проблем

## Матч не срабатывает

- убедитесь, что файл подключён через `imports` в `match/base.yml`;
- проверьте, что правило не содержит `disabled: true`;
- сохраните файл и перезагрузите конфигурацию;
- проверьте дубликаты триггеров в панели диагностики.

## Ошибки меняются во время сохранения

Studio ждёт устойчивого хеша файла перед проверкой. Старый результат остаётся на экране, пока новый снимок не будет полностью проверен. Если редактор долго пишет файл, дождитесь завершения операции.

## Конфликт внешнего изменения

Конфликт показывается, когда на диске изменились наблюдаемые файлы, а в Studio есть несохранённая рабочая копия. Сохраните нужную версию или отмените локальные изменения, затем обновите данные с диска.

## Пакет не импортируется

Проверьте, что пакет:

- имеет расширение `.respanso-config`;
- создан актуальной Studio;
- содержит `match/base.yml` или `match/base.yaml`;
- включает только YAML в `match/` и Rhai в `scripts/`;
- не содержит абсолютных путей и `..`.

## Rhai не компилируется

Откройте вкладку Rhai, выберите файл и исправьте первую синтаксическую ошибку. Одна ранняя ошибка часто порождает несколько последующих сообщений.
