# Палитра Ctrl+Space

`Ctrl+Space` открывает общую палитру rEspanso. По умолчанию активна вкладка **Триггеры**.

## Триггеры

Это прежний поиск Espanso по триггерам и содержимому шаблонов. Команды по-прежнему доступны через префикс `>`.

## Коды

Вкладка **Коды** — локальный офлайн-поиск по МКБ-10.

- поиск идёт одновременно по коду и русскому названию;
- результаты обновляются во время ввода;
- при пустой строке весь справочник не выводится;
- показывается не более 100 совпадений для одного запроса;
- `Enter` вставляет только выбранный код, например `I10`;
- `Ctrl+Tab` переключает вкладки;
- `↑/↓`, `Enter`, `Esc` работают как в обычном поиске.

Примеры запросов:

- `I48` → коды фибрилляции/трепетания предсердий;
- `гипертензия` → рубрики с этим словом в названии;
- `остеохондроз позвоночника` → соответствующие рубрики M42.

## Настройка хоткея

По умолчанию:

```yaml
search_shortcut: CTRL+SPACE
```

При необходимости значение можно изменить в `config/default.yml` стандартным способом Espanso.
