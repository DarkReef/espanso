# rEspanso Match Studio

Match Studio объединяет правила из всех YAML-файлов папки `match/`, показывает их единым списком и сохраняет неизвестные поля и комментарии.

## Правила

- **Редактор** подходит для обычных триггеров и RegExp.
- **Исходный YAML** позволяет изменить выбранный блок вручную.
- Флажок выключает YAML переименованием в `.disabled`. Если файл был импортирован из `base.yml`, Studio запоминает это и восстанавливает `imports` при обратном включении.
- Rhai-скрипты редактируются на отдельной вкладке.

## Фоновая диагностика

Studio вычисляет хеш каждого YAML- и Rhai-файла. После реального изменения она ждёт завершения записи и проверяет весь проект одним согласованным снимком.

Ошибки существуют как устойчивые экземпляры:

- прежняя ошибка обновляется на месте;
- новая появляется один раз;
- исправленная сначала помечается как исчезающая и удаляется после подтверждающей итерации;
- периодический контрольный проход выполняется примерно раз в три минуты.

Поэтому список не пересоздаётся и не «взрывается» при каждом файловом событии.

## YAML-файлы

В блоке «YAML-файлы» доступны кнопки «Создать файл» и «Удалить файл». Новый файл создаётся в папке `match` с безопасным именем и начальным правилом `:new`. Основной `base.yml`/`base.yaml` удалить нельзя. Перед удалением Studio требует отсутствие несохранённых изменений.

## Редактор правил

Структурная вкладка называется «Редактор». Отдельная кнопка «Применить изменения» больше не нужна: правки сразу попадают в рабочую копию, но остаются несохранёнными до `Ctrl+S`. Функция «Выключить триггер / правило» удалена.

## Динамические переменные в редакторе правил

Кнопка `?` рядом с текстом подстановки создаёт готовые переменные или собственную переменную. Поддерживаемые встроенные типы движка: `date`, `clipboard`, `echo`, `choice`, `form`, `random`, `rhai`, `script`, `shell`. Для удобства Studio также понимает псевдотипы:

- `time` — преобразуется в `date` с форматом `%H:%M`;
- `string` — преобразуется в `echo`, поэтому можно создать `{{doc}}` со значением `Куцин Иван Юрьевич`.

Ручной ввод `{{date}}`, `{{time}}`, `{{weekday}}` или `{{clipboard}}` автоматически создаёт недостающую запись в общих `global_vars` основного `base.yml`. Менеджер «Переменные» показывает и редактирует общие переменные из всех включённых YAML. Запись на диск выполняется только после `Ctrl+S`.

В справке также указан глобальный хоткей `Ctrl+Alt+M` — поиск триггера по выделенному тексту.


## Защита данных

- Некорректный блок правила не подменяется фиктивным `:new`: он показывается в диагностике и недоступен структурному редактору до исправления YAML.
- Переименование `global_vars` обновляет `{{имя}}` во всех текстах правил одной транзакцией.
- Имена глобальных переменных должны быть уникальны во всём проекте; межфайловые дубли отображаются в диагностике.
- «Сохранить и вставить» откатывает всю операцию при ошибке.
- Сохранение нескольких YAML восстанавливает уже записанные файлы из резервных копий при частичном отказе.
- Если секция `global_vars` содержит комментарии или YAML-якоря, структурное изменение блокируется, чтобы не потерять ручное оформление.
