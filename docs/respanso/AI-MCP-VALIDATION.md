# Проверка реализации AI/MCP

Проверка выполнена в ходе разработки 6–7 сентября 2026 года на базе `pol_run`, исходный коммит `97bd01d`.

## Подтверждено

- Полная Linux/X11 сборка движка с `modulo,vendored-tls` (формы/поиск включены).
- Сборка Match Studio с OpenGL/glow и отдельная компиляция KDE/GTK tray helper.
- Прогон всего workspace без пакета `espanso-ipc`: **313 тестов прошли, 0 ошибок, 1 тест штатно игнорируется**. После последней проверки аргументов MCP повторно прошли 9 тестов `espanso-ai`.
- MCP запущен настоящим подпроцессом `espanso-editor --mcp` без DISPLAY: initialize → initialized → tools/list → prepare_text. Получены корректные JSON-RPC ответы, три инструмента, маскированный текст; постороннего вывода в stdout нет.
- Настоящий Match Studio запущен в виртуальном X11 на Ubuntu, разрешение 1280×900. Осмотрены главный экран и вкладка ИИ: кириллица и элементы управления отображаются. Найдено и устранено наложение кнопок панели; исправленный главный экран осмотрен повторно.
- `bash -n scripts/build_pol_run_astra17.sh` и `git diff --check`.

## Ограничения и оставшиеся проверки

- В полном прогоне два теста `espanso-ipc` не смогли создать Unix-сокеты: `Operation not permitted`. Три других теста этого пакета штатно игнорируются. Пакет исключён только из дополнительного локального прогона; из CI не исключён. Работа связки daemon/worker и сквозного Alt+L в этом окружении не подтверждена.
- Среда сборки и визуальной проверки — Ubuntu, не Astra. Локальная полная сборка использовала wxWidgets 3.2, а portable CI использует Debian 10, wxWidgets 3.0 и проверяет GLIBC ≤ 2.28. Проверка конкретной Astra 1.7/KDE, её политик доступа, системного трея и взаимодействия с МИС остаётся обязательной приёмкой.
- Запросы к реальным OpenAI/GigaChat с пользовательскими ключами не выполнялись. Проверены структура запросов, разбор ответов, отсутствие сети при отключённом ИИ, локальная маскировка и ограничения MCP. Квоты, доступность конкретной модели и сертификаты сети МО не проверены.
- Полное автоматическое обезличивание не заявляется. Локальные регулярные выражения могут пропускать идентификаторы; исходящий текст и контекст требуют проверки.
- Автоматическая вставка возвращается в сохранённое X11-окно, но не восстанавливает прежнюю позицию курсора или выделение. До вставки их нельзя менять; иначе следует использовать ручное копирование.

## Исправления совместимости, обнаруженные при работе

- X11: повторное копирование того же выделения теперь отличается от отсутствия копирования, даже если буфер уже содержал такой же текст.
- Toolbar Studio переносит кнопки на следующую строку; минимальная ширина окна уменьшена до 800 пикселей.
- Проверка блокировки Studio распознаёт имя `espanso-editor`.
- CI проверяет фактическую ветку/PR вместо жёсткого checkout `pol_run`; для PR в `pol_run` включена полная portable-сборка с тестами всего workspace и отдельной проверкой MCP.
- В пакет входят xdotool, libxdo и mcp.sh. xdotool находится в `bin`, чтобы не мешать экспорту пользовательских скриптов.
