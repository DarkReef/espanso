# Завершение форка rEspanso

## Финальная редакция

- native Windows portable без BAT/CMD;
- Match Studio для нескольких YAML;
- встроенная Rhai IDE;
- безопасный перенос `match/` и `scripts/`;
- постоянная грозовая анимация трея;
- грозовой логотип в Studio;
- фирменные иконки Windows EXE;
- хеш-ориентированное наблюдение за файлами;
- устойчивые экземпляры диагностик;
- русская пользовательская документация.
