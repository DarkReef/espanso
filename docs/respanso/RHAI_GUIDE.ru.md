# Rhai в rEspanso

Rhai подходит для локальных вычислений и преобразования текста без Python, PowerShell и Node.js.

## Расположение

Скрипты хранятся в `scripts/`. Match Studio рекурсивно показывает все файлы `.rhai`.

## Доступные тестовые переменные Studio

- `trigger` — строка с триггером;
- `input` — введённая строка;
- `clipboard` — тестовое содержимое буфера обмена.

## Рекомендации

- возвращайте итоговое значение последним выражением;
- делайте поведение детерминированным;
- проверяйте пустые входные данные;
- не используйте бесконечные циклы;
- не помещайте персональные данные в демонстрационные примеры;
- после изменения дождитесь фоновой проверки проекта.

Пример:

```rhai
let value = input.trim();
if value == "" {
    "Данные не указаны"
} else {
    `Получено: ${value}`
}
```
