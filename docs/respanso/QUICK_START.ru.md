# Быстрый старт rEspanso Portable

1. Полностью распакуйте архив в обычную папку с правом записи.
2. Запустите `rEspanso.exe`.
3. Откройте меню грозовой иконки в системном трее.
4. Выберите **«Открыть студию rEspanso»**.
5. Создайте правило или отредактируйте `match/base.yml`.
6. Сохраните изменения и перезагрузите конфигурацию из трея.

## Основные файлы

```text
rEspanso/
├── rEspanso.exe
├── rEspanso-core.exe
├── rEspanso Match Studio.exe
├── config/default.yml
├── match/base.yml
├── scripts/
└── docs/
```

Активный трей постоянно анимирован. При ручной остановке подстановок значок становится статичным.
